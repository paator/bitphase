# Bitphase documentation

Bitphase is a modern web chiptune tracker for creating music on retro sound chips—designed especially for AY-based hardware and multi-chip setups. Compose music for anything from classic AY systems to experimental configurations with any number or combination of chips. The flexible song structure lets you mix and layer chips just like you would in real hardware, or invent something unique.

Open the tracker at [bitphase.app](https://bitphase.app/).

## Current chip support

| Chip                | Status                                            |
| ------------------- | ------------------------------------------------- |
| AY-3-8910 / YM2149F (MSX, Atari ST, ZX Spectrum 128k) | Primary - full editor, playback, and export paths |
| 2A03 / 2A07 (NES)   | Experimental - available as a WIP song type       |
