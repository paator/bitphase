# Bitphase documentation

Bitphase is a modern web chiptune tracker for creating music on retro sound chips. Compose for classic AY systems, NES, or SAA1099, and mix chips in one project. The flexible project structure lets you layer chips the way real hardware does, or invent a combination of your own.

Open the tracker at [bitphase.app](https://bitphase.app/) or build the app yourself (see how [here](/getting-started)).

## Current chip support

| Chip                                                  | Status                                            |
| ----------------------------------------------------- | ------------------------------------------------- |
| AY-3-8910 / YM2149F (MSX, Atari ST, ZX Spectrum 128k) | Primary - full editor, playback, and export paths |
| 2A03 / 2A07 (NES)                                     | Supported - editor, playback, import, and export  |
| SAA1099 (SAM Coupé, CMS / Game Blaster)               | Work in progress - editor, playback, E-Tracker import, and VGM |
